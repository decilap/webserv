🚀 Bonus 1: Support de Multiples Types CGI

Exécution de scripts Python ET Shell via CGI/1.1

💡 Pourquoi Multiple CGI?

Le sujet demande de supporter au moins 2 types de CGI différents pour montrer la flexibilité du système d'exécution. Notre implémentation permet d'associer n'importe quelle extension à n'importe quel interpréteur.

📜 Référence: Subject Chapter V - Bonus part

🔧 Implémentation Technique

📁 src/config/LocationConfig.hpp

class LocationConfig {
    private:
        // Map: extension → interpréteur
        std::map<std::string, std::string> _cgi_handlers;

    public:
        // Ajouter un handler CGI
        void addCgiHandler(const std::string& ext,
                            const std::string& interpreter) {
            _cgi_handlers[ext] = interpreter;
        }

        // Récupérer l'interpréteur pour une extension
        std::string getCgiHandler(const std::string& ext) {
            if (_cgi_handlers.count(ext))
                return _cgi_handlers[ext];
            return "";
        }
};

🔄 Processus d'Exécution CGI

1

Détection Extension

Le serveur parse l'URI et extrait l'extension (.py, .sh, etc.)

2

Lookup Interpréteur

Recherche dans la map pour trouver l'interpréteur associé

3

Fork + Execve

Création processus enfant qui exécute: /usr/bin/python3 script.py

4

Variables CGI

Passage des variables d'environnement (REQUEST_METHOD, QUERY_STRING, etc.)

5

Capture Output

Lecture stdout du child via pipe, avec timeout de 3 secondes

location /cgi-bin {
    root www/cgi-bin;

    # Associer .py à Python
    cgi .py /usr/bin/python3;

    # Associer .sh à Bash
    cgi .sh /bin/bash;

    # Méthodes autorisées
    allow_methods GET POST;
}

🍪 Bonus 2: Cookies et Gestion de Sessions

Implémentation complète du système de cookies HTTP

💡 Qu'est-ce que les Cookies?

Les cookies HTTP sont des petites données stockées côté client qui permettent de maintenir un état entre les requêtes HTTP (qui sont normalement stateless). Ils sont essentiels pour l'authentification, le panier d'achat, les préférences utilisateur, etc.

🔄 Cycle de vie d'un Cookie

1. Serveur → Client: Header Set-Cookie: name=value
2. Client stocke: Le navigateur sauvegarde le cookie
3. Client → Serveur: Header Cookie: name=value dans chaque requête
4. Serveur lit: Variable CGI HTTP_COOKIE

💻 Code Complet d'Implémentation

📁 www/cgi-bin/session.py

#!/usr/bin/env python3
import os, sys, time
from http.cookies import SimpleCookie

# 1. Parser les cookies reçus du client
cookies = SimpleCookie()
cookie_header = os.environ.get('HTTP_COOKIE', '')
if cookie_header:
    cookies.load(cookie_header)  # Parse: "name=value; name2=value2"

# 2. Récupérer ou créer la session
session_id = cookies.get('session_id')
if session_id:
    # Session existante → incrémenter compteur
    session_id = session_id.value
    visit_count_cookie = cookies.get('visit_count')
    visit_count = int(visit_count_cookie.value) if visit_count_cookie else 1
    visit_count += 1
else:
    # Nouvelle session → générer ID unique
    session_id = str(int(time.time() * 1000))  # Timestamp en ms
    visit_count = 1

# 3. CRITIQUE: Envoyer headers avec \r\n
#    (Python print() génère \n, pas suffisant pour CGI!)
sys.stdout.write("Content-Type: text/html\r\n")
sys.stdout.write(f"Set-Cookie: session_id={session_id}; Path=/; Max-Age=3600\r\n")
sys.stdout.write(f"Set-Cookie: visit_count={visit_count}; Path=/; Max-Age=3600\r\n")
sys.stdout.write(f"Set-Cookie: username=demo_user; Path=/; Max-Age=3600\r\n")
sys.stdout.write("\r\n")  # IMPORTANT: ligne vide entre headers et body

# 4. Générer HTML avec infos session
print("<html><head><title>Session Demo</title></head>")
print("<body style='font-family: Arial; padding: 30px;'>")
print(f"<h1>Session ID: {session_id}</h1>")
print(f"<h2>Visit #{visit_count}</h2>")
print(f"<p>Status: {'Returning visitor' if visit_count > 1 else 'First visit'}</p>")
print("</body></html>")

⚠️ CRITICAL: Headers doivent utiliser \r\n

Problème rencontré: Initialement, le code utilisait print() qui génère seulement \n. Le serveur cherche \r\n\r\n pour séparer headers et body, donc les headers s'affichaient comme texte brut!

❌ Incorrect (print):
print("Set-Cookie: ...")
print("")
# → Génère: \n\n (FAUX!)
✓ Correct (sys.stdout.write):
sys.stdout.write("...\r\n")
sys.stdout.write("\r\n")
# → Génère: \r\n\r\n (BON!)

Solution: Utiliser sys.stdout.write() avec \r\n explicites pour les headers CGI.

📤 Exemple Headers Set-Cookie Générés

Set-Cookie:
session_id=1761833695792; Path=/; Max-Age=3600

→ ID de session unique, valide 1 heure

Set-Cookie:
visit_count=3; Path=/; Max-Age=3600

→ Nombre de visites, incrémenté automatiquement

Set-Cookie:
username=demo_user; Path=/; Max-Age=3600

→ Données utilisateur arbitraires

📝 Format: name=value; [Path=path]; [Max-Age=seconds]; [HttpOnly]; [Secure]
